## 一、产品介绍

这是一套为中小企业、个体创业者、内容创作者和电商卖家设计的 **AI 自动化工作流搭建指南**。

每个工作流都来自真实的市场需求调研，包含完整的场景描述、触发条件、处理步骤、输出结果、推荐工具组合、详细配置步骤、ROI 预估和常见问题解决方案。

你不需要懂编程，只要跟着配置步骤一步步操作，就能在 1-3 小时内搭建起一套真正能跑的自动化流程。

### 包含的 5 个工作流

| 编号 | 工作流名称 | 核心价值 | 适用平台 |
|------|-----------|---------|---------|
| 01 | 客户咨询自动分类与回复 | 7×24小时秒回客户，人工只处理复杂问题 | Coze / n8n |
| 02 | 内容排期与多平台分发自动化 | 一次创作，自动适配抖音/视频号/小红书/公众号 | n8n / Make.com |
| 03 | 数据整理与报表自动生成 | 每天自动汇总数据，生成可视化报表 | n8n / Coze |
| 04 | 电商商品信息自动优化 | 批量优化标题、详情、关键词，提升搜索排名 | Coze / n8n |
| 05 | 竞品监控与情报收集 | 自动追踪竞品动态，第一时间收到预警 | n8n / Make.com |

## 三、适合人群

### 强烈推荐以下人群使用

**1. 中小企业主 / 个体老板**
- 团队人数 1-20 人
- 一个人干多个岗位的活
- 想用 AI 提效但不知道从哪开始

**2. 电商卖家（淘宝/拼多多/抖音/跨境）**
- 每天处理大量客户咨询
- 需要优化商品信息提升转化
- 想监控竞品价格和动态

**3. 内容创作者 / 自媒体运营**
- 需要多平台分发内容
- 想建立稳定的内容排期
- 粉丝互动回复压力大

**4. 运营 / 市场 / 行政岗位**
- 每天要整理数据做报表
- 需要收集竞品情报
- 想从重复劳动中解放出来

**5. AI 自动化学习者 / 自由职业者**
- 想系统学习 Coze / n8n / Make.com
- 想接自动化外包项目
- 需要可参考的实战案例

### 不适合以下情况

- 你的业务完全不需要自动化（纯线下手工服务）
- 你已经有专业开发团队做了定制系统
- 你不愿意花 1-3 小时学习基本配置

## 四、使用方法

### 第一步：选择你需要的工作流

打开对应的编号文件，先读「场景描述」和「预估效果与ROI」，判断是否适合你的业务。

### 第二步：准备工具账号

每个工作流的「推荐工具组合」部分会列出你需要注册的平台的清单。建议先准备好：
- Coze 账号（国内版：coze.cn，海外版：coze.com）
- n8n 账号（云端：n8n.io，或自部署）
- Make.com 账号（make.com）
- 对应平台的 API Key（如OpenAI、飞书、企业微信等）

### 第三步：跟着配置步骤操作

打开「详细配置步骤」章节，按顺序操作。每个步骤都写明了：
- 在哪个平台操作
- 点击哪个按钮
- 填入什么参数
- 预期看到什么结果

建议边看边操作，遇到问题先查「常见问题与解决方案」。

### 第四步：测试和上线

配置完成后，先用测试数据跑一遍，确认输出符合预期，再接入真实业务数据。

## 五、工具平台说明

### Coze（扣子）

- **网址**：coze.cn（国内版）/ coze.com（海外版）
- **特点**：字节跳动出品，中文友好，内置大量插件，适合搭建对话机器人和轻量工作流
- **费用**：基础功能免费，高级功能按量计费
- **适合**：客服机器人、内容生成、轻量自动化

### n8n

- **网址**：n8n.io
- **特点**：开源工作流自动化工具，节点丰富，可自部署，适合复杂业务逻辑
- **费用**：云端版有免费额度（每月1000次执行），自部署完全免费
- **适合**：数据同步、多平台集成、定时任务、复杂条件分支

### Make.com（原 Integromat）

- **网址**：make.com
- **特点**：可视化拖拽操作，界面直观，集成应用多
- **费用**：免费版每月1000次操作，付费版从 $9/月起
- **适合**：多平台分发、可视化流程设计

### 三个平台怎么选？

| 需求场景 | 首选平台 | 原因 |
|---------|---------|------|
| 对话机器人 / 客服 | Coze | 内置对话能力，中文体验好 |
| 复杂数据处理 | n8n | 节点灵活，可写自定义代码 |
| 多平台分发 | Make.com | 可视化操作直观 |
| 预算为零 | n8n 自部署 | 完全免费 |
| 快速上手 | Coze | 学习成本最低 |
